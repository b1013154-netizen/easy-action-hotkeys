# かんたん操作ショートカット

レポジトリ名：**easy-action-hotkeys**

好きなキーを押して、登録した動きをまとめて実行するデスクトップツールです。日本語の画面で、操作を記録したり、動作カードを順番に並べたりできます。登録上限は**100件の操作セット**です。

## 初めて使う方

Windowsの配布ZIPを展開し、`EasyActionHotkeys` フォルダの `EasyActionHotkeys.exe` をダブルクリックしてください。フォルダ内の `_internal` は実行に必要です。EXEだけを別の場所へ移動しないでください。Pythonのインストールは不要です。

1. 「新しい操作を登録」を押し、分かりやすい名前をつけます。
2. キーの入力欄をクリックし、使いたいキーを実際に押します。例：`Ctrl + Alt + F10`。ほかのアプリで使っていない組み合わせを選んでください。
3. 「動きを追加」で手順を作るか、「実際の操作を記録」で動きを覚えさせます。
4. 「保存する」を押します。
5. 「登録キーでの実行を有効にする」をオンにします。
6. 操作するアプリを手前に出し、登録したキーを押して離します。3秒後に開始します。

**Esc** で実行・記録を停止します。**F8** は記録の終了、**F7** は記録中のチェック状態の保存に使います。この3つは呼び出しキーに登録できません。アプリを閉じるとキー監視も終了します。

## 登録できる動き

- マウス移動、左・右・中央クリック、ダブルクリック、ドラッグ、スクロール。
- 日本語・改行を含む文章入力、キーの組み合わせ、キーを押す・離す。
- 指定した時間の待機。
- 画像を探してクリック。対象が現れるまで指定時間待ちます。
- ボタンの情報を読み取ってクリック。WindowsではUI Automation、MacではAccessibilityを使います。
- チェック項目を、現在の状態に関係なくオン・オフに合わせる。
- 接続した画面それぞれのスクリーンショットをPNGで保存。

手順の変更、削除、順序変更、1手順の試運転、操作セットの複製、名前での検索、JSONへの書き出し・読み込みに対応します。操作セットは100件、各セットは2000手順までです。

## 位置・画像・ボタンを選ぶ

**位置**：「画面で選ぶ」を押してから4秒以内に、対象へマウスを置きます。クリックする必要はありません。固定位置の操作に向きます。

**画像**：対象がある画面を選び、「画面で画像を囲む」を押して、文字やアイコンを含む範囲をドラッグします。単色の領域や小さすぎる画像は使えません。同じ画像が複数ある場合は停止します。倍率やテーマが変わった場合は選び直してください。

**ボタン**：「画面でボタンを選ぶ」を押して、4秒以内に対象を指します。ボタンの名前・種類・アプリなどから探します。同じ情報の候補が複数あれば停止します。情報を公開しないアプリは画像指定を使ってください。

次のページでの操作には、画像・ボタン指定の「待つ秒数」を設定します。Windowsのボタン探索は手前のウィンドウ、Macは手前のアプリを対象にします。画面遷移後も対象アプリを手前に置いてください。

## 操作を記録する

記録は4秒後に始まります。マウスの移動・クリック・ドラッグ・縦スクロールと、キーの押下・解放を手順にします。F8またはEscで終了し、現在の手順の最後に追加します。キー入力も保存されるため、記録中にパスワードを入力しないでください。日本語のIME入力は、記録後に「文字を入力」の動きへ置き換えると安定します。横スクロールやペンタブ固有の動作は記録対象外です。

記録中にF7を押すと、手前の画面のチェック項目を認識し、オン・オフの状態を手順へ追加します。画面右上の成功表示を確認してから次の操作へ進んでください。表示されていない項目はスクロールして再度F7を押すか、個別に「チェックをオン・オフにする」を登録します。

## Chromeの履歴削除

「Chrome履歴削除の登録案内」で期間と削除項目を選び、案内に沿って**実際のChrome画面の操作を記録**します。選択内容は記録時の案内で、Chrome側にも同じ設定を選ぶ必要があります。このツールがChromeへ削除APIを送る方式ではありません。

削除画面を開き、期間を選び、各項目のチェック状態を確認し、F7で状態を保存してから削除ボタンを押します。チェック状態は再生時に指定の状態へ合わせるため、単純にチェックを反転する動作より再現しやすくなります。記録中に押した削除も実際に実行されます。

保存パスワード・パスキーは、Googleパスワードマネージャーで項目を指定する別の操作として登録してください。Chromeの現在の仕様では、拡張機能のパスワード削除APIは廃止されています。Chromeの版・画面言語・配置が変わった場合は対象を選び直してください。Chromeでの削除の実機テストは未実施です。

- [Chrome公式：閲覧データを削除する](https://support.google.com/chrome/answer/2392709?hl=ja)
- [Chromium公式：パスワード削除APIの変更](https://groups.google.com/a/chromium.org/g/chromium-extensions/c/SC6prEbMbkY)

## 保存場所

- Windows：`%LOCALAPPDATA%\EasyActionHotkeys\actions.json`
- Mac：`~/Library/Application Support/EasyActionHotkeys/actions.json`

保存のたびに直前のデータを `actions.backup.json` に残します。読み込み時にデータが壊れている場合は、元データを上書きせずに案内します。読み込んだ登録は無効の状態で取り込むので、内容を確認してから有効にしてください。入力文章や対象画像もJSONに含まれます。登録データはクラウドへ送信しません。

`EASY_ACTION_DATA` 環境変数で別の保存フォルダを指定できます。同じ保存先での二重起動は防止します。

## Windows・Macの対応状況

WindowsとMacの共通画面とOS別のボタン認識を実装しています。**Windowsはローカルでビルド・実動作確認済み、Macは実機未検証**です。検証した範囲は [検証結果](docs/検証結果.md) に記載しています。

Macでは「システム設定 → プライバシーとセキュリティ」のアクセシビリティ、入力監視、画面収録を実行アプリへ許可し、再起動してください。開発用Pythonで起動する場合はPythonやターミナルにも許可が必要な場合があります。管理者権限のWindowsアプリ、ロック画面、認証・保護画面などは操作できない場合があります。OSのアクセシビリティ呼び出しが応答している間は停止が遅れることがあります。

呼び出しキーは他のアプリにも届きます。既存のショートカットと重複しないキーを選んでください。OSや他アプリ側のキー競合は検出できません。

## 開発・配布

Python 3.12を推奨します。依存関係は `requirements.txt` に記載しています。

```powershell
# Windows
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
# 配布用ZIPを生成
powershell -ExecutionPolicy Bypass -File build_windows.ps1
```

```bash
# Mac（Mac上で実行）
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
bash build_macos.sh
```

配布ファイルは `dist` に生成します。MacのビルドはMac上で行います。Mac配布物の署名・公証は未設定です。現時点でMacの実行ファイルはこのWindows環境から生成していません。

ソースと資料の登録先は [b1013154-netizen/easy-action-hotkeys](https://github.com/b1013154-netizen/easy-action-hotkeys) です。GitHub ActionsでWindows・MacのテストとZIP作成を行うワークフローを同梱しています。ビルド成果物は実行完了後のActions画面からダウンロードできます。`.venv`、`build`、`dist`、画面キャプチャや利用者の登録データはGitへ追加しません。配布ZIPを公開するときはReleasesなどへ添付してください。

$env:QT_QPA_PLATFORM = 'offscreen'
